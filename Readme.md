# GreenQuest 綠野尋蹤

A gamified plant identification web app. Photograph plants, let AI identify them, answer quiz questions to earn XP, and level up your virtual pet.

The entire UI is in Traditional Chinese.

## Installation Guideline

The repository is designed for LAN deployment. To get started, you need a server connected to LAN with a static IP.

1. Clone this repository
```
git clone git@github.com:GordanY/greenquest-local.git
```

2. Install dependencies

- NodeJS v22.22.0
- Spacetime DB v2.0.2
